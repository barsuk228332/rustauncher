# rustauncher

Лёгкий менеджер Wine / Proton префиксов с GUI на egui. Сделан «для себя»:
без демонов, баз данных и фоновых сервисов — один бинарь и один TOML.

## Что умеет

- **Префиксы**: создание (`wineboot`), список, удаление, папка префикса, версия Windows
- **Раннеры**: системный `wine` + скачивание `wine-ge` / `Proton-GE` прямо с GitHub
- **Приложения**: привязка exe к префиксу, аргументы, запуск в один клик
- **DLL overrides**: свои для префикса (например `version=n,b` для MelonLoader)
- **Журнал**: что происходит, чтобы не гадать «почему не запустилось»

## Интерфейс

- Тёмная графитовая тема с приглушённым оранжевым акцентом.
- Боковая навигация: **Приложения · Префиксы · Раннеры · Настройки**.
- Главная страница — карточки приложений; отдельные страницы для префиксов
  и раннеров, настройки.
- Компактная панель событий снизу: последняя запись, раскрытие журнала,
  очистка.
- Диалоги создания префикса, настройки приложения и подтверждения удаления.
- Масштаб интерфейса в «Настройках» (70–160 %).
- Иконки векторные, рисуются средствами egui: без растровых ассетов
  и тяжёлого SVG-рендерера.

Всё хранится в:

```
~/.config/rustauncher/config.toml          # настройки
~/.local/share/rustauncher/runners/        # скачанные раннеры
~/.local/share/rustauncher/prefixes/       # префиксы по умолчанию
```

## Сборка и запуск

```bash
# Rust-тулчейн (если ещё нет)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env

cargo run --release
```

Для сборки GUI нужны только runtime-библиотеки (libX11, libxkbcommon, libwayland,
libGL/libEGL) — на Fedora они уже есть. Dev-пакеты не требуются: winit грузит их
через dlopen.

## Заметки

- `WINEDLLOVERRIDES` для запуска собирается из overrides префикса и приложения.
- При создании префикса wineboot запускается с `mscoree,mshtml=` — чтобы не
  всплывали окна установки Wine Mono/Gecko.
- Proton-GE запускается через свой `files/bin/wine`, путь подставляется
  автоматически.
